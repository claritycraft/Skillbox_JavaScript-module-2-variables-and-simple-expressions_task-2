### Ru:
#### Задача 2
Цель задания
Научиться работать с вводом данных с клавиатуры, используя окно ввода prompt(), и доработать существующую программу.

#### Что нужно сделать

- Скачайте архив «Задача 2» и распакуйте его.
- Откройте проект в редакторе кода и запустите его в браузере, используя расширение Live Server. 
- Это программа расчёта стоимости покупки с выводом результата в консоль. Сейчас все данные уже присвоены в переменные. Добавьте возможность ввода данных всех товаров, используя окно ввода prompt(), а именно ввод - названия товара, стоимость и количество.
- Добавьте в программу расчёт стоимости всей покупки и выведите результат в консоль.

#### Пример финального вывода в консоль:

Молоко 75

Кофе 420

Яблоки 160

Сумма всей покупки: 655

#### Критерии выполнения задания
- Код работает корректно, в консоли нет ошибок.
- Все данные товаров вводятся с помощью prompt().
- В консоль выводится стоимость каждого товара с учётом количества и сумма всей покупки.

### En: 
#### Task 2
Learn to work with keyboard input using the prompt() window and improve an existing program.


#### Instructions
- Download and extract the archive “Task 2”.
- Open the project in a code editor and run it in the browser using the Live Server extension.
- This is a purchase cost calculator that outputs results to the console.
Currently, all data is hardcoded into variables.
Add functionality to input product data using the prompt() window — specifically: product name, price, and quantity.
- Add logic to calculate the total cost of the purchase and display the result in the console.

#### Example of final console output

Milk 75  
Coffee 420  
Apples 160  
Total purchase amount: 655

#### Completion Criteria
- The code runs correctly with no errors in the console.
- All product data is entered via prompt().
- The console displays the cost of each product (taking quantity into account) and the total purchase amount.
